# 国内安卓市场上架（CN Android Markets）

把一个 Android App 上到华为应用市场等国内商店（个人主体）。来自 2026-09 真实上架（小兔头节拍器 / Bunny Metronome，工具类、无账号、无后端）全程复盘，所有坑实际踩过。

## 前置决策：主体资格（先查再干，别白干）

- **小米**：注册向导只有企业 / 政府事业单位 / 港澳台企业 / 其他组织四类单选，**个人通道关闭**（2026-09 实测）。检测法：管理中心 → 开发者注册 → 看主体类型单选有没有「个人」。没有就直接跳过小米，别纠缠。
- **华为**：个人可上。实名三选一：人脸 / 银行卡（即时）、身份证人工（1–2 天）。登录后进控制台会先跳实名向导，类型选「个人开发者」。
- OPPO / vivo / 荣耀：随华为过审后跟进即可，个人主体可行但逐家确认。

## APP 备案（所有国内商店的硬前置，最长关键路径）

规则与材料：

- **一个自然人只能在一个省管局有主体**；新增备案的地区必须与已有主体属地一致。证件地址所在省 = 免居住材料的最稳选择（常住地与证件地址不同省时，常住地通常要居住证）。
- **名称三统一**：备案名 = 商店应用名 = 软著名（若登记）。
- **域名**：后缀须在工信部可备案名单（domain.miit.gov.cn 查）；域名实名主体 = 备案主体；**子域名（产品.主域）是推荐做法**——每个产品一条 App 备案、各填各的子域，父域无需单独备案，多产品互不影响。
- 阿里云流程（beian.aliyun.com → 免费自助「标准表单」，万小智 AI 助手**不支持** App 备案）：服务码（大陆地域 + 包年包月 + 剩余 ≥3 个月的 ECS/轻量）→ 主体信息（身份证 + 人脸）→ App 信息（名称 / 包名 / 签名 MD5）→ 初审 1–2 工作日 → **工信部短信核验 24h 内点掉** → 管局 ≤20 工作日。
- 只备 Android 就够：iOS 走 App Store 分发，Apple 不要求国内备案号。

实际踩的坑：

- **证件号下有外省旧主体 → 「下一步」直接被拦**（提示与已有主体「所属区域（X省）」保持一致）。排查三板斧：① 公共查询按姓名（只查得到网站类，同名者会误导——阿里云拦截按**证件号**匹配，同名不同证不背锅）② 查拟用域名有无历史备案（0 条则排除前主人遗留）③ APP/小程序类备案**公开渠道按人不可查**，是盲区——判定实验：草稿地区临时改成报错里的省，看拦截是否消失（消失即坐实）。
- 客服路径：阿里云备案专线 **4008013260**；工单（smartservice 控制台，产品分类选「ICP备案」）可查主体，但客服可能误解为「你要提供备案号」——需澄清「本人从未办过备案、没有备案号，请按证件号反查拦截依据」。也可能电话回访直接告知查无记录（此时重试草稿看拦截是否自愈）。
- **阿里云备案页的「信息校验」接口对自动化点击经常卡死 loading**（同一会话人工点击正常）。遇到卡死让用户手点，别让 agent 反复重试烧时间。

## 软著（仅应用宝硬要求；华为 / 小米不需要）

2026-03 起中国版权保护中心新版申请表要求**手抄承诺「未使用 AI 编写代码 / 撰写文档 / 生成登记材料」**，失实进失信名单并挂钩个人征信。AI 辅助开发的项目：**搁置**，等「如实声明」口径出现；应用宝一并后置，不挡华为/小米。

## 渠道包工程（market flavor 模式）

- 维度 `market`：`play`（Billing + 工坊内购）/ `cn`（全免费 + 打赏入口、无 Billing 依赖、无统计 SDK、不收集数据）。
- **编译期切换 UI，零反射零运行时开关**：同名同签名 `@Composable` 双源集（`src/play/.../ui/MarketSection.kt` 工坊段 与 `src/cn/.../ui/MarketSection.kt` 打赏段），主代码直接调用，按变体解析。
- 商店门面：main 里声明 `MarketStore` 接口（launch / close + suspend 四件套），每 flavor 一个 `createMarketStore` 工厂（play 包 PlayStoreAdapter，cn 返回空实现）。
- 依赖切分：`billing` 走 `playImplementation`；**收款码图片只进 cn res**（合规上 play 包内不能有收款码）；打赏弹窗 = AlertDialog + painterResource，资源放 `drawable-nodpi`。
- 引 flavor 后 CI 任务名全变（assembleDebug → assemblePlayDebug 等），release.yml / DEPLOY 文档必须同步，否则 CI 秒挂。

## 签名钥匙管理（所有渠道共用一把）

- 本地 keystore（如 `~/keystores/`），不进 git。指纹获取：`keytool -list -v`（新 JDK 不吐 MD5，用 `keytool -exportcert -rfc | openssl x509 -fingerprint -md5`）。备案要 MD5，华为后台要 SHA256。
- 密码入 Bitwarden：条目 = 隐藏字段密码 ×2 + alias + 指纹 + **jks 文件 base64 本体**（凭 vault 可完整还原）+ 还原命令。本地明文 env 确认导入后删除。
- CLI 坑：bw 2026.x 的 import 是**位置参数** `bw import bitwardenjson <file>`（没有 --format）；unlock 偶发 "Error parsing the encoded request data"（接口抖动，重试即过）与密码输错（报 decryption failed，和错密码的本地报错一样）。

## 官网 APK 分发（无商店时的补充渠道）

- Vercel：APK 放**仓库根 `download/`**（`.vercelignore` 若排除了 `android/` 就必须放根目录）；固定文件名（如 `jpq-latest.apk`）覆盖更新，链接标注版本 + 大小。
- **只发 cn 包**——play 包带 Billing 不走官网。同包名同签名意味着各渠道可互相覆盖升级，但 play 已购用户覆盖装 cn 包后内购段消失（装回即恢复），客服口径要知道。
- 安装坎（页面上给提示能救一个是一个）：微信内置浏览器会把 APK 改名 `.apk.1` → 下载卡下加「右上角···→在浏览器打开」；纯血鸿蒙（NEXT）**不认 APK**；小米新机要插 SIM 卡才让装第三方；华为要开「安装外部来源应用」。Android 8.0+ 全机型可装，纯 Kotlin 无 .so 则不分架构。

## 华为 AGC 控制台（浏览器自动化实战坑）

- 建应用路径：APP 与元服务 → **Android 页签** → 新建发布 → 创建应用（名称 / 分类是两级：先「应用」再二级，默认语言简中）→ AppID 在「信息中心」信息卡。包名不用手填：**首传 release APK 时 AGC 自动读取绑定**。
- 「协议包变更」弹窗必须先确认：复选框在 dialog 容器内，勾选后「我同意」才亮。**没确认前它盖住创建表单，症状是创建表单里下拉全点不开**——先怀疑遮挡，再怀疑控件。
- Element Plus 控件：el-select 要点外壳 `.el-select`（不是 input；占位 span 盖着 input，真实 click 会超时但报错会写 covered by `<span>`，这是定位线索）。下拉弹层是 position:fixed，`offsetParent` 判可见会漏，用 getBoundingClientRect。
- 页面比 800 宽视口宽时元素出屏、一切真实点击超时——`setViewportSize(1440x900)` 先行。右上引导 tooltip 先「知道了」。
- 备案号在**提审时**才填；提审包 = release 签名 APK + 截图（必须 cn 包实拍：设置页无工坊段、有打赏入口，与 play 包长得不一样）。

## 上传自动化（上线后优化项，不挡首提）

- 华为：AGC **Publishing API**（官方：token → 取上传地址 → 传包 → 提审）+ 现成 GitHub Action "Deploy to Huawei App Gallery"；凭据在 AGC「用户与权限 → API Key → Connect API」。
- 小米：开放平台「自动发布接口」（个人通道关闭期间无意义）。
- 第三方多市场 CLI（apkgo / 小蜜蜂传包等）：**用前过一遍源码**再交凭据。

## 时间线（真实参照）

账号实名 ~1 天 ∥ 备案提交 → 备案号 ~2–4 周 ∥ 渠道包工程 ~1 天 ∥ 截图半天。提审 = 备案号 + 签名 APK + 截图 + 商店文案，四者齐了才点。
